# Гитарный Тюнер 🎸

Десктопное приложение для настройки классической 6-струнной гитары в реальном времени с современным графическим интерфейсом.

## Возможности

- 🎵 Захват звука с микрофона в реальном времени
- 🎯 Точное определение базовой частоты (±0.3 Гц)
- 🎸 Поддержка 3 гитарных строев (Standard, Half-step down, Drop D)
- 🎨 Современный темный интерфейс (CustomTkinter)
- 📊 Визуальная индикация отклонения с прогресс-баром
- 🔇 Фильтрация фонового шума
- ✅ Цветовая индикация (зеленый/оранжевый)
- 🧵 Многопоточная архитектура (GUI не зависает)

## Быстрый старт

### 1. Установка

```bash
git clone <repo-url>
cd guitar-tune
pip install -r requirements.txt
```

### 2. Запуск GUI версии

```bash
python3 main.py
```

### 3. Запуск консольной версии (опционально)

```bash
python3 main_console.py
```

**Важно (macOS):** Дайте разрешение на микрофон в Системных настройках → Конфиденциальность → Микрофон

## Использование

1. Запустите приложение
2. Выберите строй из выпадающего списка
3. Нажмите "▶ Начать настройку"
4. Дерните струну на гитаре
5. Смотрите на результат:
   - Большая буква показывает ноту
   - Прогресс-бар показывает отклонение
   - Цвет меняется: **зеленый** = настроено, **оранжевый** = расстроено

**Цветовая индикация:**
- ✅ **НАСТРОЕНА** (зеленый) = отклонение ±5 центов
- ↑ **ПЕРЕТЯНУТА** (оранжевый) = ослабить струну
- ↓ **НЕДОТЯНУТА** (оранжевый) = натянуть струну

## Архитектура GUI

```
Main Thread (GUI)
    ├── CustomTkinter UI
    │   ├── Tuning selector (OptionMenu)
    │   ├── Note display (Label)
    │   ├── Frequency display (Label)
    │   ├── Progress bar (CTkProgressBar)
    │   └── Start/Stop button
    │
    └── Queue for data updates

Audio Thread
    ├── AudioEngine (sounddevice)
    ├── PitchDetector (autocorrelation)
    └── Data → Queue → GUI
```

## Технические характеристики

- **Частота дискретизации:** 44100 Гц
- **Точность:** ±0.3 Гц
- **Задержка:** ~50 мс
- **Диапазон:** 60-400 Гц (E2-E5)
- **Алгоритм:** Автокорреляция + FFT
- **GUI Framework:** CustomTkinter 5.2+
- **Многопоточность:** Threading + Queue

## Устранение неполадок

### Тюнер не реагирует

1. Запустите: `python3 test_microphone.py`
2. Играйте ГРОМЧЕ
3. Микрофон ближе (10-20 см)
4. Только одна струна (глушите остальные)
5. Дайте струне звучать 2-3 сек

Подробнее: [TROUBLESHOOTING.txt](TROUBLESHOOTING.txt)
