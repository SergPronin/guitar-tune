# Гитарный Тюнер - Руководство пользователя

## Обзор

Этот проект представляет собой гитарный тюнер в реальном времени с консольным интерфейсом. Программа захватывает звук с микрофона, определяет частоту звучащей струны и показывает, насколько она расстроена.

## Что уже реализовано (Core)

### ✅ Модуль конфигурации (`config.py`)
- Поддержка 3 гитарных строев: Standard, Half-step down, Drop D
- Точные расчеты частот нот по музыкальной формуле
- Расчет отклонения в центах
- Поиск ближайшей ноты к измеренной частоте

### ✅ Детектор питча (`pitch_detector.py`)
- Алгоритм автокорреляции для определения основной частоты
- Фильтр шума (Noise Gate) на основе RMS
- Точность определения: ~0.1-0.3 Гц
- Диапазон частот: 60-400 Гц (E2-E5)
- Параболическая интерполяция для повышения точности

### ✅ Аудио-движок (`audio_engine.py`)
- Захват звука с микрофона в реальном времени
- Частота дискретизации: 44100 Гц
- Размер блока: 2048 фреймов (~46 мс задержки)
- Неблокирующая обработка в отдельном потоке

### ✅ Консольный тюнер (`main.py`)
- Визуальная шкала отклонения (-50 до +50 центов)
- Цветовая индикация (зеленый/красный)
- Буфер сглаживания (3 измерения)
- Выбор строя при запуске

## Быстрый старт

### 1. Запуск тестов

```bash

python test_all.py

# Или по отдельности:

```

### 2. Запуск тюнера

```bash
# Вариант 1: Через скрипт (рекомендуется)
./run_tuner.sh

# Вариант 2: Напрямую
python main.py
```

## Как использовать тюнер

1. **Запуск**: Выполните `python main.py`

2. **Выбор строя**: При запуске выберите строй (1-3) или нажмите Enter для Standard

3. **Настройка струны**: 
   - Дерните струну на гитаре
   - Смотрите на экран:
     ```
     ✓ НАСТРОЕНА | Нота: A2 | Частота: 110.05 Гц (цель: 110.00 Гц) | Отклонение: +0.8 центов | [------------------------●------------------------]
     ```
   
4. **Интерпретация результатов**:
   - **✓ НАСТРОЕНА** (зеленый) - струна настроена идеально (±5 центов)
   - **↑ ПЕРЕТЯНУТА** (красный) - ослабьте струну
   - **↓ НЕДОТЯНУТА** (красный) - натяните струну
   - Шкала `[---●---]` показывает положение: центр = идеально

5. **Выход**: Нажмите `Ctrl+C`

## Строи гитары

### Standard (E A D G B E)
Стандартный строй для классической и акустической гитары:
- 1 струна: E4 (329.63 Гц)
- 2 струна: B3 (246.94 Гц)
- 3 струна: G3 (196.00 Гц)
- 4 струна: D3 (146.83 Гц)
- 5 струна: A2 (110.00 Гц)
- 6 струна: E2 (82.41 Гц)

### Half-step down (Eb Ab Db Gb Bb Eb)
Все струны опущены на полтона. Популярен в рок-музыке.

### Drop D (D A D G B E)
6-я струна опущена на тон (D вместо E). Популярен в металле и альтернативном роке.

## Устранение неполадок

### Проблема: "Аудиоустройства не найдены"
**Решение**:
- Проверьте подключение микрофона
- На macOS: Системные настройки → Безопасность и конфиденциальность → Микрофон → разрешите доступ Terminal/Python
- Запустите: `python test_audio.py` для диагностики

### Проблема: Частота не определяется (нет вывода)
**Решение**:
- Играйте громче - уровень сигнала ниже порога шума
- Проверьте, что микрофон направлен на гитару
- Играйте отдельные ноты, не аккорды
- Убедитесь, что в помещении тихо

### Проблема: Неточное определение частоты
**Решение**:
- Играйте ближе к микрофону
- Избегайте фонового шума
- Дерните одну струну, дайте ей звучать
- Не глушите струну сразу

### Проблема: Программа зависает
**Решение**:
- Нажмите `Ctrl+C` для выхода
- Перезапустите программу
- Проверьте, что другие программы не используют микрофон

## Рекомендации по настройке

1. **Тишина**: Настраивайте в тихом помещении
2. **Одна струна**: Глушите остальные струны рукой
3. **Чистый звук**: Дерните струну около резонаторного отверстия
4. **Дайте звучать**: Не глушите струну сразу, дайте ей звучать 2-3 секунды
5. **Точность**: Для точной настройки добивайтесь отклонения ±2 цента

## Структура кода

```
config.py              # Модель данных: строи, частоты, расчеты
    ├── TuningConfig                 # Класс для работы со строями
    ├── calculate_frequency()        # f = 440 * 2^(n/12)
    ├── calculate_cents()            # C = 1200 * log2(f1/f2)
    └── find_closest_note()          # Поиск ближайшей ноты

pitch_detector.py      # Алгоритм определения частоты
    ├── PitchDetector                # Класс детектора
    ├── calculate_rms()              # Фильтр шума
    ├── autocorrelation()            # Автокорреляция через FFT
    └── detect_pitch()               # Основной метод

audio_engine.py        # Захват аудио
    ├── AudioEngine                  # Класс аудио-движка
    ├── audio_callback()             # Callback для sounddevice
    ├── start()                      # Запуск захвата
    └── stop()                       # Остановка

main.py               # Главный модуль
    ├── GuitarTunerCore              # Ядро тюнера
    ├── process_audio()              # Обработка аудио
    ├── display_tuning_info()        # Вывод в консоль
    └── main()                       # Точка входа
```
