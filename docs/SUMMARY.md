# Гитарный Тюнер - Итоги разработки CORE

## ✅ Что реализовано

### 1. Модуль конфигурации (`config.py`)
**Класс**: `TuningConfig`

**Функциональность**:
- ✅ Словарь строев (Standard, Half-step down, Drop D)
- ✅ Расчет частоты ноты по формуле: f = 440 * 2^(n/12)
- ✅ Расчет отклонения в центах: C = 1200 * log2(f_current / f_target)
- ✅ Поиск ближайшей ноты из строя к измеренной частоте

**Тестирование**: ✅ Полностью протестировано
```bash
python config.py
```

---

### 2. Модуль определения питча (`pitch_detector.py`)
**Класс**: `PitchDetector`

**Функциональность**:
- ✅ Алгоритм автокорреляции для определения F0 (основной частоты)
- ✅ Фильтрация шума через RMS (Noise Gate)
- ✅ Параболическая интерполяция для точности
- ✅ Диапазон: 60-400 Гц (E2-E5)
- ✅ Точность: ~0.1-0.3 Гц

**Алгоритм**:
1. Вычисление RMS → фильтрация шума
2. Нормализация сигнала
3. Автокорреляция через FFT
4. Поиск первого значимого пика
5. Параболическая интерполяция
6. Вычисление частоты из периода

**Тестирование**: ✅ Протестировано с синтетическими сигналами
```bash
python pitch_detector.py
```

**Результаты тестов**:
```

A2 (110.00 Гц) → 110.02 Гц (ошибка: 0.02 Гц) ✓
D3 (146.83 Гц) → 147.10 Гц (ошибка: 0.27 Гц) ✓
G3 (196.00 Гц) → 196.15 Гц (ошибка: 0.15 Гц) ✓
B3 (246.94 Гц) → 247.24 Гц (ошибка: 0.30 Гц) ✓

```

### 3. Модуль захвата аудио (`audio_engine.py`)
**Класс**: `AudioEngine`

**Функциональность**:
- ✅ Захват аудио с микрофона через sounddevice
- ✅ Частота дискретизации: 44100 Гц
- ✅ Размер блока: 2048 фреймов (~46 мс)
- ✅ Обработка в отдельном потоке (non-blocking)
- ✅ Очередь аудиоданных (queue)
- ✅ Callback для обработки

**Тестирование**: ⚠️ Требует микрофон (не работает в песочнице)
```bash
python test_audio.py
```

**Класс**: `GuitarTunerCore`

**Функциональность**:
- ✅ Интеграция всех модулей
- ✅ Консольный интерфейс с визуализацией
- ✅ Выбор строя при запуске
- ✅ Цветовая индикация (зеленый/красный)
- ✅ Визуальная шкала отклонения [-50...+50 центов]

**Вывод**:

**Запуск**:

## 🎵 Математическая база

### Расчет частоты ноты
```
f_n = 440 × 2^(n/12)
```
где n — полутона от A4 (440 Гц)

### Отклонение в центах
```
C = 1200 × log₂(f_current / f_target)
```

### Автокорреляция
```
R(τ) = Σ[x(t) × x(t+τ)]
```
через FFT: `R = IFFT(|FFT(x)|²)`
