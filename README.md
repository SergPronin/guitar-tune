# Гитарный Тюнер 🎸

Десктопное приложение для настройки классической 6-струнной гитары в реальном времени.

## Возможности

- 🎵 Захват звука с микрофона в реальном времени
- 🎯 Точное определение базовой частоты (±0.3 Гц)
- 🎸 Поддержка 3 гитарных строев (Standard, Half-step down, Drop D)
- 📊 Визуальная индикация отклонения в центах
- 🔇 Фильтрация фонового шума
- ✅ Цветовая индикация (зеленый/красный)

## Быстрый старт

### 1. Установка

```bash
git clone <repo-url>
cd guitar-tune
pip install -r requirements.txt
```

### 2. Проверка микрофона

```bash
python3 test_microphone.py
```

### 3. Запуск тюнера

```bash
python3 main.py
```

**Важно (macOS):** Дайте разрешение на микрофон в Системных настройках → Конфиденциальность → Микрофон

## Использование

1. Выберите строй (1-3) или Enter для Standard
2. Дерните струну
3. Смотрите результат:

```
✓ НАСТРОЕНА | Нота: E4 | Частота: 329.78 Гц (цель: 329.63 Гц) | Отклонение: +0.8 центов
[-------------------------●------------------------]
```

- **✓ НАСТРОЕНА** (зеленый) = идеально (±5 центов)
- **↑ ПЕРЕТЯНУТА** (красный) = ослабить
- **↓ НЕДОТЯНУТА** (красный) = натянуть

## Технические характеристики

- **Частота дискретизации:** 44100 Гц
- **Точность:** ±0.3 Гц
- **Задержка:** ~50 мс
- **Диапазон:** 60-400 Гц (E2-E5)
- **Алгоритм:** Автокорреляция + FFT

## Устранение неполадок

### Тюнер не реагирует

1. Запустите: `python3 test_microphone.py`
2. Играйте ГРОМЧЕ
3. Микрофон ближе (10-20 см)
4. Только одна струна (глушите остальные)
5. Дайте струне звучать 2-3 сек

Подробнее: [TROUBLESHOOTING.txt](TROUBLESHOOTING.txt)
