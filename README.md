# 🎸 Гитарный Тюнер

Десктопное приложение для настройки классической 6-струнной гитары в реальном времени.

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## Возможности

- Захват звука в реальном времени с микрофона
- Точность определения частоты ±0.3 Гц
- Современный темный интерфейс
- Визуальная шкала от -50 до +50 центов
- Автоматическая фильтрация фонового шума
- Поддержка 3 строев: Standard, Half-step down, Drop D

## Быстрый старт

### Установка

```bash
git clone <repo-url>
cd guitar-tune
pip install -r requirements.txt
```

### Запуск

```bash
python guitar_tuner.py
```

### Настройка разрешений (macOS)

Системные настройки → Конфиденциальность → Микрофон → разрешите доступ для Terminal/Python, затем перезапустите Terminal.

## Использование

1. Выберите строй в выпадающем списке
2. Нажмите "НАЧАТЬ НАСТРОЙКУ"
3. Играйте на струне и следите за индикатором
4. Настройте струну, когда индикатор покажет зеленый цвет (±5 центов)

### Статусы

- 🟢 **НАСТРОЕНА** - отклонение ≤ 5 центов
- 🟡 **ПОЧТИ** - отклонение 5-10 центов
- 🟠 **РАССТРОЕНА** - отклонение > 10 центов

## Устранение неполадок

### Тюнер не реагирует

1. Проверьте микрофон: `python tests/test_microphone.py`
2. Играйте громче - расстояние до микрофона 10-20 см
3. Глушите соседние струны
4. Дайте струне звучать 2-3 секунды

### Нет доступа к микрофону

**macOS:** Системные настройки → Конфиденциальность → Микрофон  
**Windows:** Параметры → Конфиденциальность → Микрофон
