# 🎸 Гитарный Тюнер Pro

Профессиональное десктопное приложение для настройки классической 6-струнной гитары в реальном времени.

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Возможности

- 🎵 **Захват звука в реальном времени** - работа с микрофоном через sounddevice
- 🎯 **Высокая точность** - определение частоты с точностью ±0.3 Гц
- 🎨 **Современный интерфейс** - профессиональный темный дизайн на CustomTkinter
- 📊 **Визуальная шкала** - 51 сегмент от -50 до +50 центов с анимацией
- 🔇 **Фильтрация шума** - автоматическое подавление фонового шума
- ✅ **Цветовая индикация** - зеленый/желтый/оранжевый статус настройки
- 🎸 **3 строя** - Standard, Half-step down, Drop D
- 🧵 **Плавная анимация** - сглаживание показаний, 33 FPS

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий
git clone <repo-url>
cd guitar-tune

# Установите зависимости
pip install -r requirements.txt
```

### Запуск

```bash
# GUI версия (рекомендуется)
python guitar_tuner.py

# Консольная версия
python main_console.py
```

### Первый запуск

1. **Дайте разрешение на микрофон** (macOS):
   - Системные настройки → Конфиденциальность → Микрофон
   - Разрешите доступ для Terminal/Python
   - Перезапустите Terminal

2. **Запустите приложение**

3. **Нажмите "НАЧАТЬ НАСТРОЙКУ"**

4. **Играйте на гитаре** и смотрите на результат!

- 🟢 **НАСТРОЕНА** - отклонение ≤ 5 центов (идеально)
- 🟡 **ПОЧТИ** - отклонение 5-10 центов (близко)
- 🟠 **СЛИШКОМ ВЫСОКО/НИЗКО** - отклонение > 10 центов

### Строи

- **Стандарт** (Standard): E2, A2, D3, G3, B3, E4
- **Полутон ниже** (Half-step down): Eb2, Ab2, Db3, Gb3, Bb3, Eb4
- **Дроп D** (Drop D): D2, A2, D3, G3, B3, E4

## 🎨 Архитектура

### Core (Ядро)

- **config.py** - конфигурация строев, математика (частоты, центы)
- **pitch_detector.py** - алгоритм определения частоты (автокорреляция)
- **audio_engine.py** - захват звука с микрофона (sounddevice)

### UI (Интерфейс)

- **guitar_tuner_gui.py** - главный GUI класс
- **constants.py** - константы (цвета, размеры, параметры)

### Многопоточность

```
Main Thread (GUI)
    ├── CustomTkinter UI
    ├── Queue для данных
    └── root.after(30) для обновления

Audio Thread
    ├── AudioEngine (sounddevice)
    ├── PitchDetector (autocorrelation)
    └── Data → Queue → GUI
```

## 🐛 Устранение неполадок

### Тюнер не реагирует

1. **Проверьте микрофон**: `python tests/test_microphone.py`
2. **Играйте ГРОМЧЕ** - микрофон ближе к гитаре (10-20 см)
3. **Только одна струна** - глушите остальные
4. **Дайте звучать** - 2-3 секунды

### Нет разрешения на микрофон

**macOS:**
1. Системные настройки → Конфиденциальность
2. Микрофон → разрешите Terminal/Python
3. Перезапустите Terminal

**Windows:**
1. Параметры → Конфиденциальность → Микрофон
2. Разрешите доступ приложениям

Подробнее: [docs/TROUBLESHOOTING.txt](docs/TROUBLESHOOTING.txt)

## 💡 Советы по настройке

1. 🤫 **Тишина** - настраивайте в тихом месте
2. 🎸 **Одна струна** - глушите соседние
3. 🎵 **Чистый звук** - дергайте около резонатора
4. ⏱️ **Дайте звучать** - 2-3 секунды
5. 🎯 **Точность** - добивайтесь ±2 центов
