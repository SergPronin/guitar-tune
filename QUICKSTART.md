# Быстрый старт - Гитарный Тюнер

## 🎸 Что это?

Консольный гитарный тюнер в реальном времени. Слушает звук с микрофона, определяет частоту и показывает, насколько струна расстроена.

## ⚡ Быстрый запуск (3 шага)

### 1. Проверка зависимостей
```bash
python test_all.py
```
Должно показать:
- ✓ Конфигурация строев: OK
- ✓ Детектор питча: OK
- ⚠️ Аудио-движок: Требуется настройка (это нормально в песочнице)

### 2. Дать разрешение на микрофон
**macOS**: 
- Системные настройки → Конфиденциальность → Микрофон
- Разрешить Terminal/Python

**Windows**: 
- Параметры → Конфиденциальность → Микрофон
- Разрешить доступ приложениям

### 3. Запустить тюнер
```bash
python main.py
```

## 🎯 Как пользоваться

1. Запустить: `python main.py`
2. Выбрать строй (1-3) или Enter для Standard
3. Дернуть струну
4. Смотреть на экран:

```
✓ НАСТРОЕНА | Нота: E4 | Частота: 329.78 Гц (цель: 329.63 Гц) | Отклонение: +0.8 центов
[-------------------------●------------------------]
         слабее              OK           сильнее
```

**Интерпретация**:
- **✓ НАСТРОЕНА** (зеленый) = идеально (±5 центов)
- **↑ ПЕРЕТЯНУТА** (красный) = ослабить струну
- **↓ НЕДОТЯНУТА** (красный) = натянуть струну
- **●** на шкале показывает положение

## 📋 Строи

### Standard (E A D G B E)
Стандарт для классической и акустической гитары

### Half-step down (Eb Ab Db Gb Bb Eb)
Все струны на полтона ниже (рок, метал)

### Drop D (D A D G B E)
6-я струна опущена на тон (альтернатива, метал)

## ❓ Проблемы и решения

### Нет звука / частота не определяется
- Играйте громче
- Микрофон ближе к гитаре
- Тише в помещении
- Играйте отдельные ноты, не аккорды

### "Аудиоустройства не найдены"
- Проверьте микрофон (подключен?)
- Дайте разрешение (см. шаг 2 выше)
- Попробуйте внешний микрофон

### Неточное определение
- Глушите соседние струны
- Дайте струне звучать 2-3 секунды
- Убедитесь в тишине вокруг

## 🎵 Советы по настройке

1. **Тишина** - настраивайте в тихом месте
2. **Одна струна** - глушите остальные
3. **Чистый звук** - дергайте около резонатора
4. **Дайте звучать** - 2-3 секунды
5. **Точность** - добивайтесь ±2 центов для идеальной настройки

## 📊 Технические параметры

- **Частота дискретизации**: 44100 Гц
- **Задержка**: ~50 мс
- **Точность**: ±0.3 Гц
- **Диапазон**: 60-400 Гц (E2-E5)
